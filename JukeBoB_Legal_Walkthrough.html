📱 What is JukeBoB?

A simple explanation of our entertainment platform

In Simple Terms

JukeBoB is a party entertainment application that allows people at events, bars, weddings, or private parties to interact with the DJ or entertainer through their smartphones.

The Core Idea

Instead of walking up to a DJ to request a song, guests can use our app to submit song requests along with optional tips. The DJ sees all requests on their screen and decides which songs to play.

💡 Think of it like...

A digital jukebox where party guests can request songs and tip the DJ, combined with a game room where people can play games together, and an AI assistant that helps mix music.

Three Main Features

🎵 Jukebox

  • Guests request songs
  • Optional tipping system
  • Priority queue for bigger tips
  • Real-time updates for everyone

🎮 Games

  • Play games with other guests
  • Currently: Tic Tac Toe
  • Real-time multiplayer
  • Fun emoji reactions

🎤 The DJ's Journey

Step-by-step process for the host/entertainer

1

Create a Session

The DJ opens JukeBoB and creates a new "jukebox session." They give it a name (e.g., "John's Wedding Reception") and set a password to keep it secure.

2

Get a Session Code

The platform generates a unique code (like "ABC123") and a QR code. The DJ displays this code so guests can join their session.

3

View the Dashboard

The DJ sees a dashboard showing: all song requests, who requested them, tip amounts, and the order songs should be played.

4

Manage the Queue

The DJ can: mark songs as "played" when finished, skip songs (tips are refunded if skipped), and see total earnings in real-time.

5

Cash Out

At any time, the DJ can "checkout" to receive their tips. JukeBoB takes a 5% platform fee, and the DJ receives the remaining 95%.

💡 Example

If a DJ collects ₹1,000 in total tips during a party, they receive ₹950 (after JukeBoB's ₹50 platform fee).

🎉 The Guest's Journey

Step-by-step process for party attendees

1

Join the Session

The guest scans the QR code displayed at the venue OR enters the session code on the JukeBoB website. They enter their name and the session password.

2

See the Current Queue

The guest can see what songs are already requested and what's been played. This helps them know if their song is already in the list.

3

Request a Song

The guest enters the song name and artist. They can optionally add a tip amount. Bigger tips mean their song gets played sooner!

4

Track Their Request

The guest can see where their song is in the queue and watch it move up as other songs get played.

5

Enjoy the Music!

When their song plays, they get the satisfaction of hearing their choice at the party.

Tipping is Optional

Guests are not required to tip. They can request songs for free. However, tipping gives priority. Songs with tips of ₹10 or more go into a "VIP Queue" and are played before non-VIP songs.

📋 The Queue System

How song requests are prioritized

👑 VIP Queue

  • Requirement: Tip of ₹10 or more
  • Songs are played FIRST
  • Higher tips = Higher priority
  • Special golden highlighting
  • Crown icon displayed

🎵 Regular Queue

  • Requirement: Tip less than ₹10 (or no tip)
  • Played AFTER all VIP songs
  • First-come, first-served order
  • Standard display
  • Still gets played eventually

Example Queue Scenario

Fair Play

The queue has a maximum of 10 songs at any time to ensure songs don't wait too long. The DJ always has the final say on what gets played.

✅ Scenario A: Song Gets Played

🔄 Scenario B: Song Gets Skipped (Refund Protection)

Guest tips ₹100 → DJ skips the song → Full ₹100 refunded to guest → DJ receives ₹0

🛡️ Customer Protection: The Refund Mechanism

This is a critical consumer protection feature. The tip money is held securely by JukeBoB until the service is delivered (i.e., the song is actually played). Here's how it works:

  • Money in Escrow: When a guest tips, the money is held by JukeBoB, NOT immediately given to the DJ
  • Song Must Be Played: The DJ only receives the tip when they mark the song as "Played" and it moves to the "Recently Played" section
  • Automatic Refund on Skip: If the DJ clicks "Skip" on a song request, the full tip amount is automatically refunded to the guest
  • No Manual Process: Refunds happen instantly and automatically - no customer support needed

Why This Matters (Legal Perspective)

This escrow-style system ensures that customers only pay for services actually rendered. The DJ cannot collect tips for songs they never play. This protects consumers from:

  • Paying for a service not delivered
  • DJs collecting tips and ignoring requests
  • Disputes over whether a song was played

⚠️ Current Status

Payment processing is currently simulated for demonstration. Real payment integration (UPI, credit cards via Razorpay/Stripe) will be added before commercial launch.

🔒 Security & Privacy

How we protect users and their data

🔐

Password Protection

Every session requires a password set by the host. Only people with the password can join. This prevents random people from disrupting events.

🔒

Encrypted Passwords

Passwords are never stored in readable form. They are encrypted using industry-standard SHA256 hashing before storage.

📱

Session Persistence

If a user closes their browser, they can resume their session with the code and password. No need to re-enter all information.

🌐

No Account Required

Guests don't need to create accounts or provide email addresses. They just enter their name and join. Minimal data collection.

Data We Collect

Data Purpose Retention
Display Name Show who requested songs Session only
Song Requests Build the queue Session only
Tip Amounts Process payments For accounting
Game Moves Play games Session only

⚠️ Current Limitation

Data is currently stored in-memory only. When the server restarts, all session data is lost. For production, we will integrate a proper database for data persistence.

📝 Summary

Key takeaways

What JukeBoB Is

A party entertainment platform that lets guests request songs from DJs and play games together, with an optional tipping system.

Business Model

JukeBoB takes a 5% fee on all tips processed through the platform. The remaining 95% goes to the DJ/host. The platform is free to use without tipping.

Key Legal Considerations

  • Tips are voluntary and not required to use the service
  • Money is held in escrow until services are rendered (song played)
  • Refunds are automatic if a song is skipped
  • No gambling or betting elements in games
  • Users don't need to create accounts (minimal data)
  • Password protection for private sessions

Current Status

The platform is fully functional but uses simulated payments. Real payment gateway integration (Razorpay/Stripe) will be added before commercial launch.
